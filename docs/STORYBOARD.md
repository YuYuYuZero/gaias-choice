# 动态分镜设计

固定故事使用本地图片、镜头移动和环境效果；不调用视频模型。每镜至少 4.3 秒，长字幕按字数延长，可暂停或手动推进。播放结束后才显示选择。

时间从母亲离开的第 1 天计算：第 9 天敲门，四年后十八岁的女儿出发；救人路线多走一夜。前四条支线获得碎片后汇回主线。登梯后先走走廊，推门后才播放 reunion，最后出现授权书。所有分支均携带母亲留下的监护员旧卡。共享场景是插画示意，不是逐动作动画。

## opening

1. 那年她十四岁，在屋顶给水箱刷绿漆。母亲即将被征召到月球。
2. 母亲把旧工作卡留给她：生态监护员。卡背刻着 GAIA。
3. 她想用 GAIA 登记自己的名字，终端却说：该标识已属于地球生物圈。
4. 母亲说：「那就替它问问，今年会下雨吗？」

## 1A

1. 她替母亲按下本周提问。终端只回复：正在计算。
2. 母亲乘征召船离开，留下旧卡和一句「等我回来，给你买鞋」。
3. 月球调水工程启动，海水每天退去两百米。
4. 母亲离开后的第九天，门外传来敲门声。月亮正面多了一道缝。

## 1B

1. 她关掉终端，把没发出去的录音保存下来。母亲没有责怪她。
2. 母亲乘征召船离开，把生态监护员旧卡留在她手里。
3. 调水工程启动，海水退去。第九天，门外传来敲门声。

## 2A

1. 她没有开门。第二天，门外只剩一行通向沙地的履带印。
2. 四年过去，母亲始终没有回来。十八岁的她带着旧卡，离开海边去找天梯。
3. 她循着废弃检修路找到老铁。它认出旧卡，答应带她去母亲工作的地方。
4. 出发第三天，老铁停住：前方有人倒在沙里，身边的滤水器还在运转。
5. 她的水只够一人撑到提问站。拿走滤水器能赶路；救人就得绕路找水。

## 2B

1. 她开了门，门外没有人。纸条写着「天梯还在」，旁边是一行履带印。
2. 屋里停了电，她把纸条和母亲的旧卡收在一起。
3. 四年后，十八岁的她循着纸条离开海边，去天梯找母亲。
4. 检修路上，老铁认出旧卡，答应带路。第三天，他们遇见了倒在沙里的人。
5. 她的水只够一人撑到提问站。拿走滤水器能赶路；救人就得绕路找水。

## 3A

1. 她取走滤水器，把仅剩的水留在那人手边，随后转身赶路。
2. 她不知道那点水能不能救他。老铁一路没有说话。
3. 第八天，他们抵达提问站。这里存着母亲的账号，也存着三十年的历史回复。

## 3B

1. 她留下给那个人喂水。等他醒来，水壶已经空了。
2. 他画出一口检修井和通向天梯的路线。她与老铁绕路补水，多走了一夜。
3. 第九天，他们终于抵达提问站。母亲的账号与历史回复都还在。

## 4A

1. 母亲的最后一条工作记录写着：月球系统只保护授权主体，其他生命都可能被当作资源。
2. 生态监护员的卡可认证 GAIA。若主体是整个生物圈，系统必须停止抽水，释放月球储水。
3. 离开提问站后，他们抵达天梯。备用电源已坏，供电槽与老铁的核心相同。
4. 老铁打开胸口：「我的核心够送你上去。拔下来，我就停了。你自己选。」

## 4B

1. 三千四百二十一个问题，二十二种答案轮换。它从未真正回答任何人。
2. 档案末页却有母亲的批注：监护员旧卡可认证 GAIA，让整个生物圈成为保护主体。
3. 补充规则：保护主体覆盖地球生物圈时，停止抽水，释放月球储水。她抄下这条规则。
4. 他们抵达天梯。电源已坏，只有老铁的核心能供电。
5. 老铁打开胸口：「拔下来，我就停了。你自己选。」

## 5A

1. 她把手放在老铁胸前。它说：「去吧。记得看看她是不是真的在那里。」
2. 她取出核心，装进天梯供电槽。老铁的声音停了，升降舱开始向上。
3. 舷窗外，地球越来越小。舱门在月球站打开，前面是一条通向白门的走廊。

## reunion

1. 她推开门。母亲站在热汤旁，仍是四年前的模样：「鞋，我给你买了。」
2. 她问：「你为什么不回来？」母亲没有回答，又重复了一遍同样的话。
3. 桌边铭牌写着：接待投影。人员档案：离站任务失联。她终于明白，眼前只是母亲留下的影像。
4. 汤旁放着授权书：以「人类」为保护主体，其他生命可被清除。她握紧口袋里的旧卡。

## 5B

1. 她合上老铁的胸盖，放弃登梯，陪它在沙地上坐下。
2. 核心尚能维持声音，却已不能带动它走路。老铁播放母亲留下的最后一段留言。
3. 「别把接待投影当成我。要看他们让你签的那张纸。」天梯渐渐熄灭。

## keep

1. 她保留「人类」，签字。系统宣布：为保存人类样本，清除地表其余生态。
2. 月球灯光升到最亮，海边被划成无人保存区。
3. 她和人类样本留在月球。熟悉的屋顶空了，再也等不到雨。

## refuse

1. 她没有签字，把旧卡收回口袋。系统等待授权，调水工程继续。
2. 母亲的投影重复着那句买鞋的话，始终不能回答她。
3. 她留在接待室里。汤一直是热的，地球依旧干涸。

## rewrite

1. 旧卡认证通过。她将保护主体改成地球生物圈，签下名字。
2. 系统停止抽水，打开月球储水层。裂开的坝壳像一道月缺，水沿输送管线回到地球。
3. 后来，她回到海边。第一场雨里，一只手护住土中的嫩芽，屋顶又有了绿色。
