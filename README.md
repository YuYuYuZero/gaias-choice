# 盖娅的选择

一款关于母亲、记忆与选择的中文互动叙事游戏。

母亲被征召上月球那年，盖娅十四岁。从海边小镇的屋顶出发，她穿过退潮后的海床与沙漠，走向天梯和月球深处的一间房间。每次选择都会留下线索，最终改变她在授权书上写下的名字。

[开始体验](https://yuyuyuzero.github.io/gaias-choice/)

## 体验内容

- 五段故事：春、断、途、月、种。
- 固定分支、可收集的故事碎片与多个结局。
- 电影感画面、开场视频、音效和键盘交互。
- 当前公开版本采用预制开场视频与固定剧情演示，不实时调用模型。

## 操作

点击选项，或使用数字键 1 / 2 / 3 选择；空格 / 回车推进，M 切换静音。建议横屏体验。

## 本地体验

在项目根目录运行：

```bash
python3 -m http.server 8000
```

浏览器打开 http://localhost:8000，点击“开始演示”。无需安装前端依赖。
