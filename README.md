# 盖娅的选择

一款关于母亲、记忆与选择的中文互动叙事游戏。

母亲被征召上月球那年，盖娅十四岁。从海边小镇的屋顶出发，她穿过退潮后的海床与沙漠，走向天梯和月球深处的一间房间。每次选择都会留下线索，最终改变她在授权书上写下的名字。

[开始体验](https://yuyuyuzero.github.io/gaias-choice/)

## 体验内容

- 五段故事：春、断、途、月、种。
- 固定分支、可收集的故事碎片与多个结局。
- 电影感动态分镜：缓慢推拉、叠化转场、雨沙光影与逐镜字幕。
- 全部固定选项采用本地分镜图播放，不实时调用模型；支持暂停、重播与手动切镜。

## 操作

点击选项，或使用数字键 1 / 2 选择；分镜会自动播放，也可使用画面右下角的暂停 / 下一镜。空格 / 回车推进剧情，M 切换静音。建议横屏体验。

## 本地体验

在项目根目录运行：

```bash
python3 -m http.server 8000
```

浏览器打开 http://localhost:8000，点击“开始故事”。无需安装前端依赖。
